# 🎨 Projeto AWAX

Landing page responsiva desenvolvida com **HTML5 e CSS3**, recriando a estrutura visual de um site institucional de uma agência digital.

O projeto foi desenvolvido como prática de **desenvolvimento Front-end**, com foco em estruturação de páginas, organização de estilos, responsividade e construção de interfaces.

## 🚀 Sobre o projeto

A página apresenta diferentes seções de um site institucional:

* 🏠 Banner principal
* 👥 Sobre a empresa
* 🛠️ Serviços
* 💼 Projetos
* 👨‍💻 Equipe
* 💬 Clientes
* 💰 Planos e preços
* 📊 Estatísticas
* 📩 Formulário de contato
* 📍 Informações de localização
* 🔗 Rodapé e redes sociais

## 🛠️ Tecnologias utilizadas

* **HTML5** — estrutura e semântica
* **CSS3** — estilização e layout
* **Flexbox** — organização dos elementos
* **Media Queries** — responsividade
* **Google Fonts** — Inter e Montserrat

## 🖥️ Como executar

Clone o repositório:

```bash
git clone https://github.com/thiagolumus/Projeto-Awax.git
```

Entre na pasta:

```bash
cd Projeto-Awax
```

Depois, abra o arquivo `home.html` no navegador.

Não é necessário instalar dependências.
